# Allow-list for scripts/check-config-drift.sh
# One PIPELINE_* token per line. Blank lines and `#` comments ignored.
# Each entry (or group) must explain WHY it is exempt.
# Entries ending in `_` are concat-prefix wildcards: they suppress any token
# whose name begins with that prefix (e.g. `PIPELINE_EVAL_` covers
# `PIPELINE_EVAL_CLASSIFIER`, `PIPELINE_EVAL_CONTAINER`, etc.). Entries shrink
# as the companion cleanup issue documents each var in pipeline.config.example.

# Concat-prefix bases for dynamic PIPELINE_* var construction. spawn-claude.sh
# and related scripts build var names like `PIPELINE_PATH_${X}_SKILLS_EXECUTE`
# at runtime via bash indirect expansion, so the bare prefix tokens appear in
# source. Also catches concrete vars sharing the prefix that haven't been
# documented yet (the cleanup sub-issue will peel each as it documents them).
PIPELINE_EVAL_
PIPELINE_PATH_
PIPELINE_CI_
PIPELINE_LABELS_
PIPELINE_CONTAINER_
